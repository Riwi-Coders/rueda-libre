# 🚲 Rueda Libre

**Explora Medellín sobre dos ruedas.**

Rueda Libre es un proyecto académico de desarrollo web realizado durante mi formación en **RIWI**. Consiste en un sitio web para explorar rutas en bicicleta por Medellín, consultar tarifas y acceder a un formulario de reservas.

El proyecto se enfoca en la creación de interfaces responsivas, la navegación entre páginas, la accesibilidad web y la implementación de frameworks CSS.

## 🌐 Demo

**[Visitar Rueda Libre](https://leinx2.github.io/rueda-libre/)**

## ✨ Características

- **Página de inicio:** presentación del servicio, información general y acceso a las principales secciones.
- **Rutas y tarifas:** información sobre los recorridos disponibles, sus características y precios.
- **Formulario de reservas:** interfaz para ingresar los datos de una solicitud de reserva.
- **Diseño responsivo:** adaptación de la interfaz a dispositivos móviles, tabletas y computadores.
- **Accesibilidad:** uso de HTML semántico, etiquetas descriptivas, navegación por teclado y atención al contraste visual.
- **Prototipado:** experimentación con Bootstrap y Tailwind CSS para construir y personalizar componentes.

> **Nota:** Rueda Libre es un proyecto académico. No representa un servicio comercial de reservas en funcionamiento.

## 📁 Estructura del proyecto

```text
rueda-libre/
├── index.html
├── paginas/
│   ├── tarifas.html
│   └── reservas.html
├── css/
├── img/
├── nocturna/
└── README.md
```

La estructura separa las páginas HTML de los recursos visuales y los estilos. La carpeta `nocturna/` contiene un prototipo desarrollado con Tailwind CSS.

## 🎯 Objetivos de aprendizaje

Durante el desarrollo de Rueda Libre se trabajaron diferentes conceptos fundamentales del desarrollo frontend:

- **HTML semántico:** organización de contenido mediante etiquetas apropiadas.
- **Rutas y navegación:** manejo de rutas relativas y enlaces entre documentos.
- **HTTP:** identificación e interpretación de respuestas como `200 OK` y `404 Not Found`.
- **Diseño responsivo:** implementación de layouts adaptables utilizando Bootstrap.
- **Tailwind CSS:** construcción de interfaces mediante clases de utilidad.
- **Accesibilidad web:** aplicación de buenas prácticas relacionadas con WCAG.
- **Control de versiones:** seguimiento de cambios mediante Git y GitHub.
- **Despliegue:** publicación del proyecto utilizando GitHub Pages.

## 🚀 Ejecución local

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/Leinx2/rueda-libre.git
   ```

2. Acceder al directorio:

   ```bash
   cd rueda-libre
   ```

3. Abrir `index.html` en un navegador o utilizar la extensión **Live Server** de Visual Studio Code.

No requiere instalación de dependencias para visualizar las páginas estáticas.
